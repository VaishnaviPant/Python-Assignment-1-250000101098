## Topics Covered in Detail

The 50 programs are organized around the following Python fundamentals:

1. **Basic Output and Comments** – Displaying messages, using print statements and writing comments.
2. **Identifiers and Variables** – Valid identifiers, variable assignments and naming conventions.
3. **Arithmetic Operations** – Mathematical calculations, swapping variables and numerical conversions.
4. **Python Data Types** – Integer, float, complex, string and Boolean.
5. **Type Conversion** – Using int(), float() and str().
6. **Built-in Functions** – Using abs(), round(), pow(), min(), max(), sum(), type(), len() and id().
7. **Python Collections** – Strings, lists, tuples and dictionaries.
8. **User Input** – Accepting and processing data using input().
9. **Formatted Output** – Displaying variables and personal details in a structured format.
10. **Constructors** – Using list(), tuple() and dict().

## Execution Instructions

### Prerequisites

- **Python Version:** Python 3.8 or higher
- **Editor:** Visual Studio Code (VS Code)
- **Dependencies:** No external libraries are required. All programs use the Python standard library.

### Run a Program

Open a terminal in the repository folder and execute an individual Python file:

```bash
python Q01.py
```

On systems where Python 3 is invoked separately, use:

```bash
python3 Q01.py
```

Replace `Q01.py` with the desired question number to execute another program.

Programs that require user input will prompt for the necessary values in the terminal.
