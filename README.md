## Execution Instructions

### Prerequisites

- **Python Version:** Python 3.8 or higher
- **Dependencies:** No external libraries are required; the programs use the Python standard library.

### Run a Program

Open a terminal in the repository folder and run an individual file:

```bash
python Q01.py
```

On systems where Python 3 is invoked separately, use:

```bash
python3 Q01.py
```

Replace `Q01.py` with the file you want to execute. Programs that require input will prompt the user in the terminal.
